# Свой веб-компонент на Lit

Когда в Vaadin нет нужной визуализации (диаграмма процесса, граф связей, схема,
таймлайн), быстрее всего написать веб-компонент на Lit. Lit уже есть в
зависимостях Vaadin, ничего добавлять не нужно.

## Файлы

- JS: `src/main/frontend/components/<tag>.js`. Заготовка:
  `assets/lit-component-template.js`.
- Java-обёртка:

  ```java
  @Tag("app-diagram")
  @JsModule("./components/app-diagram.js")
  public class Diagram extends Component implements HasSize, HasStyle {
      public void setData(String json) {
          getElement().setProperty("data", json == null ? "" : json);
      }
  }
  ```

  Компонент создаётся в Java (`new Diagram()`) и добавляется в контейнер из XML.

## Как устроить

- Данные передавай одним свойством-строкой (JSON). Разбор, раскладка и отрисовка
  выполняются в браузере в `willUpdate`, сервер ничего не знает о геометрии.
- Для графов удобна схема «SVG для рёбер + HTML для узлов»: рёбра рисуются
  кривыми Безье в SVG-слое, узлы - абсолютно позиционированными `div`. Текст,
  обрезка, наведение и анимации в HTML делаются гораздо проще, чем в SVG.
- Раскладка графа по слоям: обход в глубину помечает обратные рёбра (циклы),
  слой узла - самый длинный путь до него по прямым рёбрам, порядок внутри слоя -
  по среднему положению родителей (меньше пересечений). Обратные рёбра рисуются
  пунктирной дугой сбоку, под них резервируется запас ширины только если они есть.
- Масштаб «по ширине» считается через `ResizeObserver`, рядом кнопки `-`, `%`, `+`.
- Щелчок по узлу открывает карточку-инспектор с его параметрами. Это дёшево
  и сильно повышает ценность визуализации.
- Узлам разных типов дай свой цвет и иконку (короткие SVG-пути), подписи -
  на языке пользователя и короткие, чтобы не обрезались.
- Ошибка разбора данных показывается внутри компонента понятным текстом.

## Тема

CSS-переменные наследуются в shadow DOM. Если в `static styles` компонента
использовать переменные темы (`var(--app-surface)`, `var(--lumo-primary-color)`)
с запасными значениями, компонент сам следует светлой и тёмной теме.

## Сборка

- В режиме разработки стили темы подхватываются без перезапуска, а изменения
  JS-модулей требуют пересборки фронтенд-бандла (перезапуск приложения).
- Перед деплоем обязательно проверь production-сборку: бандл собирается иначе.
