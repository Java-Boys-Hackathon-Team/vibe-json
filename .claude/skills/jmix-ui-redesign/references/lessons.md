# Журнал уроков

Сюда добавляется опыт каждого нового проекта: что сработало, что оказалось
неожиданным, на что ушло время. Записи короткие. Общие уроки со временем
переносятся в тематические файлы `references/`, а здесь остаётся ссылка.

Формат записи:

```
## <Проект> (<Jmix>/<Vaadin>, <дата>)
- Сработало: ...
- Неожиданно: ...
- В следующий раз: ...
```
