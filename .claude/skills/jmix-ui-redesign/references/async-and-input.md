# Долгие операции и поле ввода

## Долгие операции (LLM, внешние API)

- **Общий пул потоков** - Spring-бином (`ThreadPoolTaskExecutor`), а не
  `Executors.newFixedThreadPool` в экране: пул экрана никто не закрывает, и потоки
  копятся с каждым посетителем.
- **Контекст безопасности в фоне**: Jmix требует пользователя для `DataManager`,
  поэтому работа в фоне оборачивается в
  `systemAuthenticator.withUser(username, () -> ...)`.
- **Сохранение в фоне, отрисовка в UI**: результат сохраняется в базу в фоновом
  потоке, а интерфейс только отрисовывает его. Иначе ответ теряется, если
  пользователь закрыл вкладку.

  ```java
  UI ui = UI.getCurrent();
  String username = currentAuthentication.getUser().getUsername();
  CompletableFuture
          .supplyAsync(() -> systemAuthenticator.withUser(username,
                  () -> save(entity, service.call(entity, prompt))), executor)
          .whenComplete((result, ex) -> ui.access(() -> onResult(entity, result, ex)));
  ```

  Для `ui.access` нужен `@Push` на классе приложения.
- **Привязка к сущности**: пока идёт запрос, пользователь может открыть другую
  сущность. Результат относится к той, для которой отправлен запрос; рисуй его,
  только если она всё ещё открыта, иначе покажи уведомление. Ожидающие запросы
  удобно держать в `Set<UUID>`, чтобы при переключении восстановить индикатор.
- **Ошибки**: из `CompletionException` доставай причину, текст сокращай
  (`StringUtils.abbreviate`) и показывай карточкой с кнопкой «Повторить».
- `dataManager.save(a, b)` возвращает `EntitySet`; дальше работай с
  `saved.get(a)`, а не с исходными объектами: у них может не быть
  заполненных служебных полей (дата создания и т. п.).

## Поле ввода сообщения

- Enter отправляет, Shift+Enter переносит строку:

  ```java
  Shortcuts.addShortcutListener(promptInput, this::submit, Key.ENTER).listenOn(promptInput);
  ```

  Сочетания с модификаторами под это правило не попадают.
- У поля `valueChangeMode="EAGER"`: значение на сервере актуально в момент
  нажатия Enter, а `clear()` гарантированно очищает поле в браузере (при
  отложенной синхронизации сервер может считать поле уже пустым и не отправить
  очистку).
- Поле и кнопка отправки - одна «капсула» с подсветкой при фокусе (`:focus-within`),
  под ней короткая подсказка о сочетаниях клавиш. Пока идёт ответ, блокируй
  кнопку отправки и меняй плейсхолдер, но не само поле: пользователь может
  набирать следующее сообщение.
- Первое сообщение удобно использовать как название новой сущности (беседы,
  задачи), сокращённое до 50-60 символов.
